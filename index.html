Publications

Surface Coverage Completeness for Quality-Assured Arthroscopic 3D Reconstruction

Dmitrii Bychkov, Rutwik Shah, Kaustav Mukherjee, Mitchell Ryan So

ECCV 2026 Workshop DCAMI

Used truncated signed distance function (TSDF) fusion for real-time 3D reconstruction of the knee during arthroscopic surgery. We found that oblique viewing angles lead to significant drops in reconstruction quality, which has clinical relevance during surgery.

Geometry-Conditioned Latent World Models with Recurrent Adaptation in Dynamic Environments

Kaustav Mukherjee, Salvatore Penachio, Penghao Zhu, Wen Cheng, Sankarshana Venugopal, Aneesh Jonelagadda

arXiv Submitted to ICLR 2027 (Under Review)

Introduced GeoMamba-WM, a geometry-grounded recurrent world model that encodes a pre-mapped semantic 3D point cloud and utilizes a Mamba-based State Space Model (SSM) to dynamically correct a persistent hidden state using live visual observations.

Spectral-Target Physical Latent Structuring for JEPA-Style World Models

Penghao Zhu, Salvatore Penachio, Kaustav Mukherjee, Aneesh Jonelagadda

arXiv Submitted to ICLR 2027 (Under Review)

Introduced a generalizable training-time auxiliary supervision target for jointly-trained JEPA-style world models to better structure the latent space, improving performance across various benchmark environments and doubling success rate in low-data regimes.

Multi-Task Learning for Non-Canonical Phoneme Recognition via Articulatory Feature Decomposition

Sophia Riaz, Haoze Zheng, Amos Roche, Miyu Zhang, Anamika Ragu, Salvatore Penachio, Kaustav Mukherjee, Aneesh Jonelagadda

arXiv

Used hierarchical Multi-Task Learning (MTL) and semi-supervised learning with Momentum Pseudo-Labeling (MPL) for phoneme recognition in non-canonical speech, achieveing SOTA phoneme-error rates (PER) on the L2-ARCTIC dataset.
